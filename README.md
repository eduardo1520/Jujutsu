# Jujutsu

Front-end simples para ajudar a abstrair comandos do Git usando equivalentes comuns do **Jujutsu (jj)**.

## Como usar

1. Abra o arquivo `/home/runner/work/Jujutsu/Jujutsu/index.html` no navegador.
2. Digite um comando Git (ex.: `git status`, `git add arquivo.txt`, `git commit -m "mensagem"`).
3. Clique em **Converter para jj** para ver uma sugestão de comando equivalente.

## Observações

- O mapeamento atual cobre comandos Git comuns.
- Para comandos avançados ou não mapeados, consulte a documentação oficial: https://github.com/jj-vcs/jj
